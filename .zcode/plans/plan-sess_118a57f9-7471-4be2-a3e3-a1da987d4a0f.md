Редизайн `CategoryExpensesSheet` по референсу (без графика — по решению пользователя), с собственной навигацией по месяцам и рабочими кнопками «Новый расход» и «Редактировать категорию».

## Целевой вид шита (сверху вниз)

1. Шапка: ✕ слева (закрыть) · название категории по центру · ✎ справа (редактировать)
2. Навигатор месяца: ‹ `1 авг. - 31 авг.` › — свой курсор внутри шита, данные фильтруются клиентски
3. Итог: `3 088,89 ₽ потрачено` (приглушённый)
4. Секция «Все расходы» + иконка сортировки (тумблер новые↔старые)
5. Группы по дням: дата слева, итог дня справа, тонкие разделители между строками (как в `ExpensesSheet`)
6. Строка: круглая иконка категории (цвет из данных) · описание (fallback: название категории) · сумма
7. Футер: пилюля «+ Новый расход» (переиспользовать `ExpenseSheetFooter`, с скрытием при скролле)
