# Разделение note и date в тулбаре: изолированные поля вместо общего FormActions

Проблема текущего `form-actions.tsx`: один компонент держит подписки и note (`description`), и date (`occurredAt`), и локальные состояния обоих, и submit как ребёнка — смена даты ререндеривает note-кнопку, набор заметки ререндеривает date-части, любой toggle — submit.

Структурная причина, почему поля нельзя сделать одним contiguous-компонентом: у каждого поля два визуальных места — раскрытая строка НАД общим рядом и кнопка ВНУЗИ него (`[QuickDateRow?] [NoteInput?]` над `border-t`-рядом `[note][date][submit]`). Решение: родитель — тупой layout-контейнер, владеющий только двумя boolean'ами; каждая часть поля — самоподписывающийся memo-компонент.

## Изменения

1. **`date-field.tsx` (новый)** — всё date:
   - `DateField({ open })` (memo): `useWatch('occurredAt')`, владеет `datePickerRef`, рендерит `{open && <QuickDateRow/>}` + всегда смонтированный `DatePickerSheet`; обработчики выбора даты живут здесь;
   - `DateFieldButton({ open, onToggle })` (memo): `useWatch('occurredAt')` → презентационный `DateButton`.

2. **`note-field.tsx` (расширить)** — добавить `NoteFieldButton({ open, onToggle })` (memo): `useWatch('description')` → `hasNote` → существующий `NoteButton`. `NoteInput` уже самодостаточен (свой `Controller`), не трогаем.

3. **`form-actions.tsx` (похудеть)** — `FormActions` остаётся только layout-владельцем: два boolean'а (`noteOpen`, `quickDatesOpen`) с `useCallback`-toggle'ами, обёртка `gap-4`, ряд `border-t`. Ноль `useWatch`. Toggles стабильны → memo детей работает: toggle note не ререндерит date-части и submit, и наоборот. `TransactionSubmitField` (memo + `useFormState`) остаётся приватным здесь.

4. **`new-transaction-form.tsx`** — `TransactionRootError` переезжает из `form-actions.tsx` приватным компонентом в файл формы (root-error — забота формы, не тулбара).

## Итоговая матрица ререндеров

- нажатие кейпада → только `AmountField` + submit (лишь при флипе валидности);
- выбор счёта/категории → только своё поле;
- выбор даты/чипа → `DateField` + `DateFieldButton` (это одно concern);
- ввод заметки → `NoteInput` + `NoteFieldButton`;
- toggle тулбара → только оболочка `FormActions` (memo блокирует соседей).

Визуальная раскладка и все testID не меняются: закрытые поля не рендерят host-view, `gap-4` считается так же; `formEpoch`-ремонт `FormActions` по-прежнему сбрасывает оба флага.
