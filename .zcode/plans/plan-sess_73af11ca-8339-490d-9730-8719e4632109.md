# Цвета apps/mobile: всё в токенах + uniwind-классы + новая палитра «Pastel Playful Fintech / Soft-Brutalist»

## Контекст (что нашёл аудит)

- Токен-инфраструктура есть: `apps/mobile/global.css` определяет 21 семантический цвет через `@variant light/dark`, но значения — **ручная копия** `packages/tokens` (одна из 4–5 рукописных копий палитры: `colors.ts` oklch, `colors.rn.ts` hex, `index.css`, mobile `global.css`, web `style.css`).
- **Реальные баги**: `input.tsx`, `button.tsx`, `icon-button.tsx` передают className-строки (`'text-destructive'`) в RN-пропы цвета — Ionicons/ActivityIndicator получают невалидный цвет. По правилам uniwind нужны `{prop}ClassName="accent-..."` пропы.
- ~25 мест сырых цветов: hex в className (`bg-[#f44336]`), сырая палитра (`bg-gray-200/300`, `bg-white`, `bg-emerald-100`), единственный `StyleSheet.create`, inline-стили, `colorsRN[resolvedTheme]` + `useTheme()` в компонентах вместо классов.

Решения пользователя: новая палитра в стиле Pastel Playful Fintech с Soft-Brutalist влияниями (уход от чёрного primary к индиго); **отдельные** brand-токены для акцентных чипов (не warning/success); палитра категорий токенизируется; `global.css` генерируется скриптом; визуальные правки: галочка mode-sheet → primary, «Все расходы» → success/10, кружок категории → muted (скрим SpeedDial остаётся белым).

## Шаг 2. Генератор `global.css` из tokens

Новый скрипт `packages/tokens/scripts/generate-mobile-theme.mjs` (загрузка `colors.rn.ts` через `jiti`, devDep): генерирует блок `@layer theme { :root { @variant light/dark … } }` в `apps/mobile/global.css` между маркерами `/* BEGIN/END GENERATED THEME */` (ручная часть файла — `@import`, радиусы, шрифт, утилиты — сохраняется). Скрипты: `gen:mobile-theme` + `gen:mobile-theme:check` (drift-проверка через diff, по аналогии с `make gen-check`). В сгенерированный блок включить и статические `--color-white/--color-black` из tokens.

Дополнить `apps/mobile/global.css` (ручная часть):
- `@utility shadow-card { box-shadow: light-dark(4px 4px 0 0 #1b1927, 4px 4px 0 0 #57526b); }` — фирменный offset-контур soft-brutalist (light-dark() разрешён в `@utility`, но не в `@theme`).

## Шаг 3. Миграция компонентов apps/mobile на классы/токены

**shared/ui:**
- `icon.tsx` — обернуть `Ionicons` в `withUniwind` (сторонний компонент → можно; RN-core нельзя). Новый API: `color` (только динамические данные-цвета), `colorClassName="accent-…"`, `className`.
- `button.tsx` — карта `indicatorVariantStyles` (`primary: 'accent-primary-foreground'`, …) → `<ActivityIndicator colorClassName={…} />` (фикс бага).
- `input.tsx` — `placeholderTextColorClassName="accent-muted-foreground"`; иконки → `colorClassName={hasError ? 'accent-destructive' : 'accent-muted-foreground'}` (фикс бага).
- `icon-button.tsx` — дефолт `colorClassName = 'accent-foreground'` (фикс бага).
- `card.tsx` — вариант `elevated`: `bg-card shadow-card`, убрать inline-стиль с `shadowColor: '#000'`.
- `screen-placeholder.tsx` — убрать единственный `StyleSheet.create`, перейти на классы (`text-foreground`, `text-muted-foreground`).
- `screen.tsx` — удалить мёртвый проп `backgroundColor`.
- `speed-dial.tsx` — убрать `colorsRN`+`useTheme`; `FabIcon` → `colorClassName="accent-primary-foreground"`; скрим остаётся `bg-white`, но теперь это токен (`--color-white`).

**widgets + app:**
- `bottom-tab-bar.tsx` — `Ionicons` → общий `Icon`; убрать `colorsRN`/`useTheme`/пропы `activeColor`/`inactiveColor`; внутри `TabButton`: `colorClassName={focused ? 'accent-primary' : 'accent-muted-foreground'}`, текст → `text-primary`/`text-muted-foreground`, пилюля `bg-gray-200` → `bg-muted`. Обновить `bottom-tab-bar.test.tsx`: вместо чтения цвета из `style` (под jest className не резолвится) — проверять className-строку.
- `(tabs)/_layout.tsx` — поверхность `bg-[#fafafa]` → `bg-background`; действия speed-dial: transfer → `bg-primary`, expense → `bg-destructive`, income → `bg-success` (семантические действия), иконки → `accent-*-foreground`; убрать `colorsRN`/`useTheme`.
