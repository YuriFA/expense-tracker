 Кнопка «+ Новый расход» становится плавающим оверлеем над списком; «плавный переход» — настоящий градиентный скрим на встроенной поддержке градиентов Uniwind (https://docs.uniwind.dev/faq#how-can-i-use-gradients — `bg-gradient-to-t from-… to-…` прямо в className, без доп. библиотек и без raw-цветов). Все правки — в `apps/mobile/src/pages/dashboard/ui/expenses-sheet.tsx`.

## 1. `NewExpenseFooter` → абсолютный оверлей
- Корень — сам `Animated.View`: `style={[animatedStyle, { position: 'absolute', bottom: 0, left: 0, right: 0 }]}`. @gorhom рендерит `footerComponent` внутри `BottomSheetContent` (фиксированная высота, `overflow: hidden`) — оверлей якорится к нему, а скрывающая анимация (translateY + fade) обрезается по кромке шита.
- `pointerEvents={visible ? 'box-none' : 'none'}` — вокруг пилюли тапы уходят в список; скрытая кнопка не ловит касания.

## 2. Градиентный скрим (плавный переход)
- Внутри оверлея, за пилюлей: `View` c `pointerEvents="none"` (тaps проходят к списку) и классом `absolute inset-x-0 bottom-0 h-32 bg-gradient-to-t from-white to-transparent` — список «растворяется» в фоне шита под кнопкой.
- `from-white` точно совпадает с фоном шита: @gorhom использует дефолтный белый в обеих темах (`'white'` в его styles.js) — швов нет ни в light, ни в dark. Класс-токен, design-tokens-guard проходит.

## 3. Список под кнопкой
- У RN `ScrollView` встроенный `flexGrow: 1` — когда футер выходит из layout-потока, `BottomSheetScrollView` растягивается на всю высоту шита, строки прокручиваются под кнопкой и под скримом.
- Нижний отступ контента скролла: `pb-4` → `pb-32` (128px ≈ скрим + пилюля + safe-area), чтобы последние строки прокручивались выше плавающей зоны.

## 4. Пилюля
- Остаётся `rounded-full bg-primary` + `shadow-lg` (как у speed-dial FAB) — градиент берёт переход на себя, тень добавляет глубину.

## 5. Проверки
- `pnpm type-check`, `lint`, `format`, `test` в apps/mobile — testID кнопки не меняется, jest-тесты и Maestro-флоу не затронуты.
- Визуальная проверка на загруженном симуляторе: инлайн-флоу Maestro «открыть лист → swipe» + скриншот — убедиться, что градиент рендерится, список уходит под скрим, и тапы по списку в зоне скрима работают; при необходимости подстрою высоту/плотность скрима (например `from-white/90`).
